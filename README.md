# Madyakasa on Style - SMA Negeri 3 Denpasar

> **"Be Trendsetter Not A Follower"** — Redefining teenage power.

Web application for **Madyakasa** from **SMA Negeri 3 Denpasar (Trisma)**, Bali. A youth empowerment and creative exhibition platform showcasing original pop-art, social satire, video documentation, and collective voices of students redefining what it means to be young, bold, and impactful.

## Features
- **Hero & Manifesto**: The core philosophy of Madyakasa challenging the stigma of youth conformity and celebrating teenage leadership.
- **Interactive Community Voice / Poll**: Real-time poll ("Percayakah kamu remaja dapat membawa perubahan?") with interactive voting and message wall.
- **Galeri Foto**: Featured exhibit of *PIC 1 - MAS BAHLIL* with retro comic / satire aesthetics, high-res preview, and full-screen lightbox modal.
- **Video Dokumentasi**: HTML5 documentation video player with playback controls and fallback support for Trisma video reels.
- **Animate On Scroll (AOS)**: Fluid viewport animations replicating the original visual flair.

## Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Custom Display & Serif Fonts (Lilita One, Fraunces, Plus Jakarta Sans)
- **Icons**: Lucide React
